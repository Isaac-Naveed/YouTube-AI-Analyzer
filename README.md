
# 🎥 YouTube AI Analyzer

An AI-powered YouTube video analyzer built using Python, Agno, Groq, and Streamlit.

Transform YouTube videos into structured insights with the help of an AI agent.

## ✨ Features

- 🎬 YouTube video analysis
- 📝 Detailed video summaries
- ⏱️ Meaningful timestamps
- 🧠 Key concepts and learning points
- 📚 Organized content breakdown
- 📥 Downloadable analysis reports

## 🛠️ Tech Stack

- Python
- Agno - AI Agent Framework
- Groq - LLM Inference
- Streamlit - Web Interface
- YouTubeTools - Video information and captions

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/youtube-ai-analyzer.git
```

Navigate into the project:

```bash
cd youtube-ai-analyzer
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key
```

Run the application:

```bash
streamlit run ui.py
```

## 🔐 Environment Variables

You need a Groq API key to use the application.

Get one from https://console.groq.com/

Never share your API key publicly.
